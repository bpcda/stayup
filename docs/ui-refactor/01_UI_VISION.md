# StayUp UI Vision

## Obiettivo

Trasformare l'intera applicazione StayUp nell'estetica del mockup allegato.

NON creare nuove pagine.
NON aggiungere nuove funzionalità.
NON modificare database, auth, edge functions, routing o logica applicativa.

Il lavoro è esclusivamente UI/UX.

---

## Stile generale

StayUp deve apparire come un prodotto premium.

Target percepito:
- startup nightlife premium
- SaaS/event platform da 2.000–3.000€
- dark luxury
- moderno
- minimalista

## Principi

Molto spazio bianco.

Pochi colori.

Bordi sottili.

Glow minimo.

No effetti gaming.

No glassmorphism.

No gradienti aggressivi.

No card giganti.

No elementi "cheap".

---

## Tipografia

Gerarchia forte.

Titoli:
- font-weight 600/700

Testo:
- font-weight 400/500

Line-height ampia.

Spaziatura generosa.
