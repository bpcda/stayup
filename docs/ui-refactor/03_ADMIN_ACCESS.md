# Admin Access UX

## Problema

Oggi gli admin devono conoscere la URL.

Esperienza inaccettabile.

---

## Soluzione

Se utente è:

admin
organizer

mostrare accesso dashboard da:

1. header desktop
2. pagina profilo
3. menu mobile

---

## Pagina Profilo

Aggiungere card:

Area Amministrativa

Descrizione:
Gestisci eventi, prenotazioni, check-in e lista d'attesa.

CTA:
Vai alla dashboard
