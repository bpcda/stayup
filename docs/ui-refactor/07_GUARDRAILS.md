# Strict Constraints

NON modificare:

- schema Supabase
- migrations
- edge functions
- auth
- OAuth
- waitlist
- QR
- check-in
- RPC
- hooks business logic
- servizi backend

Consentito:

- layout
- componenti UI
- css
- tailwind
- icone
- spacing
- typography
- responsive

Alla fine:

npm run typecheck

npm run build

Fornire:

- elenco file modificati
- screenshot before/after
- eventuali regressioni UI individuate
